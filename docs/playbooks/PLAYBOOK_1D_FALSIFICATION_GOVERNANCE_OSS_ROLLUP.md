| **`FALS-01` — Silent `HEAD` / `feature/*` Fix** | Issue `OPEN` (`physrisk#512`), fixed on `feature/*` ([`invest#2813`](https://github.com/natcap/invest/issues/2813)/`#2802`), or CI regression (`DeepForest#1448`). | Already fixed on `HEAD`/`feature/*` or `main` CI regression. | Check cloned `HEAD`, `feature/*`, and open PRs (`#2802`, `#1448`) first. |

| **`FALS-03` — Unlinked Open PR / Claim** | `linked_prs=[]` & `assignees=[]`, yet open PR (`invest#2819`) or comment (`DeepForest#1438`) claims it. | GitHub only links default-branch auto-close PRs; claims live in comments. | Scan open PRs (`pulls?state=open`) AND all issue comments first. |
| **`FALS-04` — Intersection vs. Union Nodata** | Assuming `~(nodata(A) & nodata(B))` is always a bug. | Intersection `~(A \| B)` is for `A + B`; Union `~(A & B)` is for `combine_first`. | Check if operator needs **both** inputs valid or **at least one**. |

| **`FALS-07` — Fake DB Imputation (`"0 NULLs"`)** | Filling unrecorded DB cols (`temp_min_c = 8.0`) to claim `"0 NULLs"`. | Makes `19,415` unmeasured spp look like `2,435` measured `FAO EcoCrop` rows. | Keep SQL `NULL` / CSV `""`; resolve at runtime via `MORPHOTYPE_DEFAULT_DIMS`. |
| **`FALS-08` — Undirected ASA & Re-Clean** | Undirected `N`-node ASA (`R² = 0.9962`) & re-cleaning reference `.mif` maps. | Undirected bounces at `p₀`; collinear merge collapses `Barnsbury` (`178 → 149`). | Use `2N` directed `(seg, dir)` (`R² = 1.00000000`) + `is_prenoded_segment_map` ([`iscvlab/sse-space-syntax`](https://github.com/iscvlab/sse-space-syntax)). |
| **`FALS-09` — `f32` `acos(dot)` & MIF `DATA`** | `float32` `segment_lengths` before `acos(dot)` & MIF `startswith("DATA")`. | `acos(x)` diverges at `x → 1.0` (`45%` err); `Data_Map_Ref` hits `startswith("DATA")`. | Normalize & run `acos(dot)` in `float64`; match `line.upper() == "DATA"` + DXF `entitydb`. |
| **`FALS-10` — Portal Bandit & `qgis.core`** | Static `Qt.*` check only, leaving `B112`/`B310` or unscoped `QgsWkbTypes.LineString`. | `plugins.qgis.org` blocks `B112`/`B310` & fails `Qt6 Check [✗]` (`pyqgis4-checker`). | Run `bandit -r` (`0` issues, no `.bandit` in ZIP) + `pyqt5_to_pyqt6.py --dry_run`. |
| **`FALS-11` — Closed Repos & `GPL`** | `0%` external-merge repos, bundled `GPL`, or superseded-SHA emails ([`geoai#960`](https://github.com/opengeos/geoai/pull/960) `d1300e9` vs `0b13f11`). | Paper repos ignore PRs; `GPL` infects binaries; GitHub expires old SHAs on merge. | Require `<= 7d` SLA + `> 0%` merge; IPC-bridge `GPL`; check merged `HEAD`. |
| **`FALS-12` — `MaskAware` Honeycomb, Non-Planar Overlap & Pooled-AP / Subset-Index Traps** | `Precision = 1.000` on sparse-GT chops (`HARV_2025` `n=525` vs `GT=18`), non-planar `IoU ≤ 0.25` overlap jumping `Dev-20` `Src-Macro F1` `+4.21 pts` (`0.7547 → 0.7968`), assuming pooled `Average AP40` equals unweighted source mean (`0.135` vs `0.308` on `OOD_per2`), or indexing `test_subset.indices[offset]` on nested PyTorch `Subset`s. | `MaskAwarePrecision` forgives unmatched canopy masks whenever `max_iou ≤ 0.40` (`46.93M` overlap px, `6.6×` `OvSplitGT`, double-counting biomass `UL-04`); `DetectionMAP` micro-pools across imbalanced tile GT counts; nested `Subset` breaks `subset.indices[offset]`. | Enforce planar `Overlap=0 px`, `Euler=1`, blind `Holdout_v18`, `Plain P` + `F1_tm_strict` + `MaskAcc` + `OvSplitGT`, & `CF3-Scoped` Gate (`Playbook 6`); report per-source `AP40/AP60` alongside pooled `DetectionMAP`, and resolve disk filenames from `DataLoader` `meta_row[filename_idx]` (`_filename_id_to_code`) instead of `Subset.indices`. |
| **`FALS-13` — Cross-Column ETL Cap Chimera** | Spliced DB caps (`#18116`: `H=25m, R=10.87m` `W/H=0.87`, `foliage=37.5kg` vs `LAI=3.44`) patched via `SLA=25`. | Forest `H` + shrub `foliage` cap yield a narrow broom & fake `SLA`. | Check `2R/H` & `foliage_kg·SLA/(πR²) ≈ LAI`; preserve `DB_REFERENCE_CAPPED` + `BOTANICAL_TRUTH_OVERRIDES` (`Test 10`). |
